### TMS App Mobile

**Project Purpose:**  
The TMS App Mobile is a discipleship companion app for the Topical Memory System (TMS). It makes scripture memorization, journaling, worship, and study easier, accessible, and portable. Whether you're on **mobile, PC, or tablet**, the app ensures you can stay consistent in your journey anytime and anywhere. Built for **CORE groups, campus ministries, and individual disciples**.

**Key Features:**

**Scripture Memory**

- **TMS Series A–E** — full verse library with audio playback per verse
- **GRID Books 1–5** — chapter-level memory with the same swipe-and-audio flow
- Vertical swipe navigation with per-verse play/pause, active-recall toggle, and audio control bar
- Series-level audio: play all, loop, and repeat-one modes with lock-screen and notification controls

**My Verses (Custom Memorization)**

- Save any verse from TMS, Grid, Journal, or typed by hand — all stored on-device, no network required
- **Collections** — organise saved verses into named, color-coded groups with a swipeable card deck per collection
- **Uncategorized** card for verses not yet assigned to a collection
- Assign and reassign verses between collections from the save sheet
- Tap the practice button on any collection card to open minigames with the saved verse text
- Save button on every TMS and Grid verse card — pre-fills reference, topic, and translated text
- Journal integration — link verses from "My Verses" alongside the scripture picker

**Discipleship Guides**

- Illustrated discipleship guides with callout, tip, verse, diagram, and text sections
- YouVersion verse chip integration — tap any chip to open the verse in YouVersion
- Reflect footer with one-tap journal entry creation

**Songbook**

- Full song lyrics with multi-language version support
- Chord overlay toggle, pinch-to-zoom, and scroll-based UI fading
- YouTube and Spotify media bar integration

**Journal**

- Seven prompt types: Free Write, Reflection, Prayer, Application, Memorization, Gratitude, Devotional, Wraps, Raising Future Parents
- Structured Devotional entry form with Bible reference picker
- Auto-save, search, and filter by type and date range
- Linked context chips for verses, songs, and guides
- Daily journaling reminder notification (configurable time)

**Verse Memorization Games**

- Flashcard flip, Fill-in-the-blank, Type-the-verse, and Rapid-fire minigames
- Haptic and audio feedback per result

**Onboarding & In-App Guidance**

- Five-slide illustrated onboarding flow with gradient backgrounds
- Nudge cards on the home screen promoting unused features
- One-time contextual hints: swipe overlay, play-button tooltip, YouVersion banner

**Home Screen Widget**

- Android home screen widget displaying the current verse
- Configurable source: TMS series or GRID books
- Verse text respects the user's selected Bible version from Settings

**Settings**

- Font size (Small / Normal / Large / Extra Large)
- Theme (Light / Dark / System)
- Language (English, Spanish, French, Swahili)
- Home screen widget source
- Daily journaling reminder toggle and time picker
- Haptic feedback toggle
- Data refresh

**Multi-language support** (Kenyan dialects + international) and **optimized for mobile-first use** with responsive design.
